## 6. ПРАВИЛА ПАРАЛЛЕЛЬНОЙ РАБОТЫ
**Безопасно параллелить (разные папки):**
- Разные `src/products/<A>` vs `<B>` — не пересекаются.
- Документация vs код. Промпт продукта vs UI лендинга того же продукта (разные файлы).

**Опасно (один файл — нужна последовательность):**
- Две задачи, трогающие любой файл в `src/lib/*` (общий слой — ломает всех).
- Две задачи, трогающие `src/products/index.ts` (реестр).
- Две задачи, добавляющие миграцию Supabase (номер `00XX` конфликтует).
- Две задачи, трогающие `src/app/api/*` один и тот же роут.
- Две задачи, трогающие `.claude/` (скилы/хуки).

**Правило для Claude Code:** перед началом сверься с разделом 2. Если новая задача трогает те же файлы, что
задача в работе — попроси owner'а подтвердить параллель или отложи.
